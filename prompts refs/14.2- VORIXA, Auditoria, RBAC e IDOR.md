## TESTES

### 1. USER sem acesso administrativo
Tentar acessar páginas e APIs administrativas.

### 2. USER_A vs USER_B
USER_B deve tentar acessar recursos de USER_A.

### 3. Job ownership
Testar Job de outro usuário.

### 4. File ownership
Testar File de outro usuário, quando aplicável.

### 5. UserId manipulado
Enviar `userId`, `ownerId` ou equivalentes no request.

### 6. Role manipulado
Tentar enviar `role=ADMIN`.

### 7. isUnlimited manipulado
Tentar alterar `isUnlimited`.

### 8. IDOR por ID
Testar IDs de Jobs, Files, Models, Tools e demais recursos acessíveis por identificador.

### 9. IDs inexistentes
Verificar resposta e não exposição de informações.

### 10. Escalação horizontal
USER_A não pode acessar recursos de USER_B.

### 11. Escalação vertical
USER não pode obter privilégios administrativos.

### 12. API direta
Executar testes diretamente nas APIs, sem depender da interface.

### 13. Métodos HTTP
Testar métodos não permitidos.

### 14. Ownership no backend
Confirmar que a autorização ocorre no servidor.
