# VORIXA, AUDITORIA 14.4: XSS, INJEÇÕES E SSRF

## OBJETIVO

Auditar exclusivamente XSS, SQL Injection, command injection e SSRF quando aplicável.

## REGRA

Testar cada categoria.

Se não aplicável, demonstrar por que.

Não marcar PASS somente por inspeção.

Classificar cada item como TESTADO, INSPECIONADO, NÃO APLICÁVEL ou NÃO FOI POSSÍVEL TESTAR.

## XSS

Testar entradas controladas pelo usuário:

- prompt;
- nomes;
- títulos;
- descrições;
- metadados;
- mensagens;
- outputs armazenados.

Procurar:

- `dangerouslySetInnerHTML`;
- `innerHTML`;
- renderização HTML;
- Markdown inseguro;
- URLs em atributos.

Testar Stored e Reflected XSS quando aplicável.

## SQL INJECTION

Pesquisar:

- `$queryRaw`;
- `$executeRaw`;
- SQL dinâmico;
- interpolação.

Executar testes não destrutivos.

## COMMAND INJECTION

Pesquisar uso de:

- `exec`;
- `spawn`;
- `shell`;
- comandos de sistema.

Verificar se input do usuário chega a comandos.

## SSRF

Verificar primeiro se o servidor aceita URLs fornecidas pelo usuário.

Se não aceitar:

`NÃO APLICÁVEL, demonstrar evidência.`

Se aceitar, realizar somente testes controlados.

## TESTES

Criar regressões para vulnerabilidades encontradas.

Executar suíte e:

```bash
npm run build
```
