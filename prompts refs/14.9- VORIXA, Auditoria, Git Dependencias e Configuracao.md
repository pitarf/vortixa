# VORIXA, AUDITORIA 14.9: GIT, DEPENDÊNCIAS E CONFIGURAÇÃO

## OBJETIVO

Auditar exclusivamente higiene do repositório, dependências e configuração de segurança.

## REGRA

Não alterar versão de dependências sem autorização.

Registrar evidências.

## GIT

Executar:

```bash
git status
git diff
git log --oneline -n 20
git remote -v
```

Pesquisar secrets no histórico.

Não executar push.

## ARQUIVOS

Verificar:

- `.env`;
- `.env.example`;
- dumps;
- logs;
- uploads;
- temporários;
- backups.

## DEPENDÊNCIAS

Auditar dependências instaladas e identificar vulnerabilidades conhecidas quando ferramentas locais estiverem disponíveis.

Não atualizar automaticamente.

## CONFIGURAÇÃO

Auditar:

- production/development;
- debug;
- source maps;
- stack traces;
- headers;
- cookies;
- secrets;
- URLs;
- CORS.

## DOCKER

Somente verificar configurações relacionadas ao projeto.

Não exigir Docker local, pois o ambiente de desenvolvimento foi definido como nativo.

## BUILD

Executar:

```bash
npm run build
```

## RELATÓRIO

Criar:

`security_audit_14_9_git_dependencies.md`

Diferenciar vulnerabilidades reais de recomendações informativas.

Ao terminar:

`AUDITORIA 14.9 CONCLUÍDA`

Não iniciar 14.10.
